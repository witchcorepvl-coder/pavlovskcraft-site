PavlovskCraft — сайт (GitHub Pages)

Файлы: index.html (главная), guides.html (гайды), css/, js/, fonts/, icon.png.

Как выложить:
1. На github.com создай репозиторий (например pavlovskcraft-site), публичный.
2. Загрузи ВСЁ содержимое этой папки в корень репозитория (Add file -> Upload files).
3. Settings -> Pages -> Source: Deploy from a branch -> Branch: main, папка / (root) -> Save.
4. Через минуту сайт будет на https://<твой-ник>.github.io/pavlovskcraft-site/

Настройки лаунчера (репозиторий и имена файлов релиза): js/site.js, начало файла.
Тексты гайдов лежат в guides.html — правь текст между тегами.
